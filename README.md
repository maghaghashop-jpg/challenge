# تحدي الـ100 ألف

موقع عربي متجاوب لمتابعة تحدي تجميع 100,000 جنيه خلال 365 يومًا، من 1 أكتوبر 2026 إلى 30 سبتمبر 2027.

## ربط Supabase

1. افتح **Supabase Dashboard → SQL Editor**.
2. شغّل محتوى `supabase/schema.sql` مرة واحدة.
3. بيانات الاتصال العامة لمشروع Supabase مضافة إلى الموقع بالفعل.
4. من **Authentication → URL Configuration** أضف رابط الموقع المنشور إلى Redirect URLs حتى يعمل رابط الدخول بالبريد.

الموقع يعمل في وضع محلي قبل الربط. بعد الاتصال وتسجيل الدخول، يدمج التقدم المحلي مع البيانات المحفوظة في Supabase.

## الأمان

- لا يستخدم الموقع `service_role key` مطلقًا.
- المفتاح المطلوب هو `anon public key` فقط.
- سياسات Row Level Security تمنع كل مستخدم من قراءة أو تعديل بيانات مستخدم آخر.
- إعداد الاتصال يُحفظ في المتصفح فقط.

## الملفات

- `dist/`: الموقع الجاهز للنشر.
- `supabase/schema.sql`: الجدول وسياسات RLS.
- `.openai/hosting.json`: إعداد نشر الموقع على Sites.

## GitHub Pages

المستودع مجهز للنشر التلقائي من مجلد `dist` عبر workflow موجود في:

`.github/workflows/deploy-pages.yml`

بعد دفع الملفات إلى فرع `main`، اختر **GitHub Actions** كمصدر Pages من إعدادات المستودع إذا لم يتم اختياره تلقائيًا. كل دفعة جديدة إلى `main` تعيد نشر الموقع.
